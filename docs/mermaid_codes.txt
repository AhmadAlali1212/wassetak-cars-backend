sequenceDiagram

    participant AC as AuthController
    participant V as Validator
    participant AT as AccountType Model
    participant U as User Model
    participant W as Wallet Model
    participant DB as 🗄️ Database

    M->>API: POST /api/register

    AC->>U: create(user_data)
    U->>DB: INSERT INTO users
    DB-->>U: User created
    U-->>AC: User object

    AC->>W: user->wallet->create(balance: 0)
    W->>DB: INSERT INTO wallets
    DB-->>W: Wallet created

    AC->>U: createToken('auth_token')
    U-->>AC: Bearer Token

    AC-->>M: 201 {user, access_token}

7. مخطط التسلسل - تقديم مزايدة
-----------------------------------------------
sequenceDiagram
    participant M as 📱 الموبايل
    participant AC as AuctionController
    participant A as Auction Model
    participant B as Bid Model
    participant DB as 🗄️ Database

    M->>AC: POST /api/auctions/{id}/bid (amount)
    AC->>A: find(id)
    A->>DB: SELECT * FROM auctions
    DB-->>A: Auction record

    alt المزاد غير موجود
        AC-->>M: 404 Not Found
    end

    alt المزاد غير نشط أو منتهي
        AC-->>M: 400 المزاد غير نشط
    end

    alt المستخدم هو البائع
        AC-->>M: 403 لا يمكنك المزايدة على مزادك
    end

    AC->>AC: validate(amount > current_price)

    AC->>DB: BEGIN TRANSACTION

    AC->>A: update(current_price = amount)
    A->>DB: UPDATE auctions

    AC->>B: create(auction_id, user_id, amount)
    B->>DB: INSERT INTO bids

    AC->>DB: COMMIT

    AC-->>M: 200 {bid, auction_current_price}

8. مخطط التسلسل - الاشتراك الشهري
-----------------------------------------------
sequenceDiagram
    participant M as 📱 الموبايل
    participant SC as SubscriptionController
    participant U as User Model
    participant W as Wallet Model
    participant T as Transaction Model
    participant S as Subscription Model
    participant DB as 🗄️ Database

    M->>SC: POST /api/subscription/subscribe
    SC->>U: check accountType

    alt نوع حساب غير مسموح
        SC-->>M: 403 Forbidden
    end

    SC->>U: hasActiveSubscription()
    alt لديه اشتراك نشط
        SC-->>M: 400 لديك اشتراك بالفعل
    end

    SC->>W: check balance >= 20000
    alt رصيد غير كاف
        SC-->>M: 400 رصيد غير كاف
    end

    SC->>DB: BEGIN TRANSACTION

    SC->>W: balance -= 20000
    W->>DB: UPDATE wallets

    SC->>T: create(type:subscription_payment, amount:-20000)
    T->>DB: INSERT INTO transactions

    SC->>S: create(start_date:now, end_date:+1month, status:active)
    S->>DB: INSERT INTO subscriptions

    SC->>U: update(is_subscribed:true, subscription_ends_at)
    U->>DB: UPDATE users

    SC->>DB: COMMIT

    SC-->>M: 200 {subscription_details}
